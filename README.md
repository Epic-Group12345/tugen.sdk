# tugen.sdk

**TUGEN запускает любое мини-приложение: сервис или игру — достаточно описать его на SDK.**

SDK для мини-приложений лаунчера TUGEN (версия 1.0.0). Мини-приложение — одна единица для любого
типа: сервис, игра, инструмент или страница. Лаунчер открывает его на месте страницы, под своими
островами. Всё, что приложение получает от системы и лаунчера, идёт через `useHost()`, и только через него.

```tsx
import { SafeAreaView, Svg, Circle, defineApp, useHost } from '@tugen/sdk';
import { Text } from 'react-native';

function App() {
  const host = useHost();
  // SafeAreaView — чтобы текст не ушёл под верхнюю плашку лаунчера
  return (
    <SafeAreaView style={{ flex: 1 }}>
      <Svg width={24} height={24}>
        <Circle cx={12} cy={12} r={10} fill="#0ea5e9" />
      </Svg>
      <Text>Память: {host.system.totalMemoryMb()} МБ</Text>
    </SafeAreaView>
  );
}

export default defineApp({
  manifest: {
    id: 'my-app',
    name: 'Моё приложение',
    version: '1.0.0',
    kind: 'game',
    icon: 'Cube',
    permissions: ['files', 'net', 'camera'],
  },
  App,
});
```

## Что в SDK

- `react-native-svg` входит в SDK: `Svg`, `Path`, `Circle`, `Defs`, `LinearGradient` и остальные
  компоненты берутся из `'@tugen/sdk'`, пакет ставить не нужно. Версия та же, что у лаунчера.
- Пакет `.map` не вшивает SDK и `react-native-svg` в себя: `@tugen/sdk` внешний, лаунчер отдаёт свою копию.

## Виды

`kind: 'service' | 'game'` — по смыслу и отображению в списке приложений. Сам API один и тот же:
сервис и игра получают одинаковые пространства хоста. Игре обычно нужны `files`, `downloads`, `process`.

## Права

`manifest.permissions` — то, что приложение просит у лаунчера:
`files`, `downloads`, `process`, `net`, `clipboard`, `camera`, `microphone`.

Лаунчер выдаёт их по доверию: встроенное приложение получает все, пакет `.map` — то, что попросил в
манифесте. Без права пространство существует, но его вызов бросает ошибку с именем права.
Тема, интерфейс (кнопки, окна), жизненный цикл, внешние ссылки, навигация, список приложений,
хранилище и система доступны всем: они не дают доступа к данным устройства.

## Хост (`useHost()`)

| Пространство | Что даёт                                                                      | Право       |
| ------------ | ----------------------------------------------------------------------------- | ----------- |
| `lifecycle`  | `ready()`, `close()`, подтверждение закрытия                                  | всегда      |
| `navigation` | раздел своего приложения (`open`), закрыть экран (`exit`)                     | всегда      |
| `apps`       | список сервисов и игр, открыть другое приложение                              | всегда      |
| `theme`      | текущая тема лаунчера (`scheme`) и её смена (`subscribe`)                     | всегда      |
| `viewport`   | размер области и отступы под островами (`size`, `safeArea`, `subscribe`)      | всегда      |
| `ui`         | главная кнопка (`mainButton`), «назад» (`backButton`), окна (`popups`), отклик (`haptics`) | всегда |
| `system`     | память, язык, система и архитектура                                           | всегда      |
| `storage`    | ключ-значение приложения между запусками                                      | всегда      |
| `db`         | собственная база SQLite приложения: `execute` (SQL) и `migrate` (миграции по версии); отдельный файл на приложение | всегда |
| `secure`     | защищённые значения (`get`, `set`, `remove`), шифруются системой (DPAPI, связка ключей) | всегда |
| `links`      | открыть ссылку в браузере (только http и https)                               | всегда      |
| `files`      | файлы только в пространстве приложения, пачки копий, ассеты                   | `files`     |
| `downloads`  | пачки загрузок с проверкой SHA-1                                              | `downloads` |
| `process`    | запуск, остановка и список процессов (игр)                                    | `process`   |
| `net`        | GET текстом и JSON с повтором при сбое сети; `request` — любой метод, заголовки и тело, статус в ответе | `net` |
| `clipboard`  | чтение и запись буфера обмена                                                 | `clipboard` |
| `camera`     | доступ к веб-камере и снимок в файл пространства                              | `camera`    |
| `microphone` | доступ к микрофону и запись в файл пространства                               | `microphone`|

Точные типы — `src/host/`. В текущей сборке лаунчера буфер обмена, камера, микрофон и отклик ещё не
подключены к оборудованию: методы отвечают «нет» и не падают. Главная кнопка и кнопка «назад» хранятся
в хосте, отрисовка в островах — следующий шаг.

## Веб

`WebView` входит в SDK (как `Svg`): страницы открываются прямо в окне приложения. Внешние ссылки — через
`host.links.open` в браузере по умолчанию. Для тестов в Node используйте заглушку, как для SVG.

## Разделы

`manifest.sections` — разделы приложения. Лаунчер помнит открытый и передаёт его пропом `section`;
переключатель рисует само приложение (`host.navigation.open(id)`).

## Иконка и название

`manifest.icon` — имя иконки Gravity UI в PascalCase (`'Cube'`). Лаунчер показывает её и название в
верхней плашке, пока приложение открыто.

## Safe Area

`useSafeArea()` и `<SafeAreaView>` дают отступы, которые закрывают острова лаунчера. Под островами
можно рисовать фон, нажимаемое и текст — внутри.

## Пакет .map

`.map` — zip с `manifest.json` (`format: 2`, `sdk`, `entry`, `app`) и бандлом CommonJS. Собирается CLI:

```bash
yarn tugen-map build                       # src/index.tsx + src/manifest.ts → dist/<id>.map
```

Ставится в лаунчер в режиме разработчика. Изоляция — на уровне модулей JS, это не граница безопасности.

## Тесты приложения в Node

`react-native-svg` в Node не грузится: в Jest-конфиге приложения отобразите его в заглушку, как сделано
в самом SDK (`test-mocks/react-native-svg.js`):

```js
moduleNameMapper: { '^react-native-svg$': '<rootDir>/test-mocks/react-native-svg.js' }
```

## Работа

```bash
yarn install
yarn typecheck
yarn test
```

## Версия

1.0.0 — переписанный контракт: `defineApp`, `kind`, `permissions`, единый хост для любого типа
приложения, `react-native-svg` в составе SDK. Мини-приложения под 0.x не совместимы; формат `.map` — 2.
